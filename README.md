I'm a third-year Computer Science student specializing in **Artificial Intelligence & Robotics** at VIT Chennai.

I'm particularly interested in the software side of robotics — designing systems that allow robots to **perceive, plan, communicate, and act autonomously**.

My current journey revolves around:

* 🤖 **ROS 2 & Robotics Software**
* 🦾 **Autonomous Robotic Systems**
* 👁️ **Computer Vision**
* 🧠 **Artificial Intelligence & LLM Applications**
* 💻 **C++ & Python**
* 🐧 **Linux & Developer Tools**

I learn primarily by **building, experimenting, breaking things, and figuring out why they broke** — which is why my GitHub is a collection of both learning repositories and practical projects.

---

## 🚀 What I'm Building

My main focus is currently shifting toward **robotics software engineering**.

I'm working with **ROS 2 Jazzy**, exploring robot communication, multi-node architectures, custom interfaces, controllers, simulation, and the foundations required to build larger autonomous robotic systems.

At the same time, I'm experimenting with modern AI architectures using **LangChain, LangGraph, RAG, local LLMs, and tool-calling agents**.

The long-term goal?

> **Build intelligent robots that can actually do useful things in the real world.**

## 📌 Featured Projects

### 🤖 [ROS 2 Learning Journey](https://github.com/DiyaJabin/ros2-learning)

A hands-on ROS 2 learning repository covering **ROS 2 Jazzy, nodes, topics, services, actions, parameters, custom interfaces, TF, RViz, and robotics software development**.

Built alongside my robotics learning journey with practical implementations and structured notes.

---

### 🐢 [Catch the Turtles — ROS 2](https://github.com/DiyaJabin/catch-the-turtles-ros2)

A ROS 2 multi-node application where a **master turtle dynamically detects and catches spawned turtles**.

The project explores:

* Custom ROS 2 interfaces
* Multi-node communication
* Dynamic entity handling
* Proportional control
* ROS 2 Python development

A small project, but a fun way to put ROS 2 concepts together into an actual working system.

---

### 🤖 Agentic AI Customer Support Automation

A multi-agent AI customer support system built using **LangGraph, RAG, SQLite memory, human-in-the-loop approval, and supervisor validation**.

The project explores how multiple AI agents can collaborate while still keeping humans involved where necessary.

---

### 🧠 AI HR Assistant

A local AI-powered HR assistant using **LangChain, RAG, FAISS, Ollama, and PDF knowledge retrieval** for policy Q&A and candidate support.

---

### 🎓 Smart College Assistant

An AI-powered academic assistant built with **LangChain, tool-calling agents, Ollama, and Python**, designed to provide intelligent assistance for college-related tasks.
